## Okuma sınırı

Bu dosyalar uygulama davranışını veya kart içeriğini değiştirmez. Olumlu
kayıtlar not/kart kimlikleri ve kendi katalog alıntılarıyla desteklenir.
Olumsuz kayıtlar mutlak yokluk garantisi değildir. Bağımsız TUS uzmanı
onayı, bütün tıbbi önermelerin doğrulaması veya sınav öncesi yakalama
kanıtı sunulmaz. Sorular ve rakip kartları bütünüyle çoğaltılmamıştır.
